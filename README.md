# JEE Progress Tracker (Class 12)

An industry-style Java tracker for JEE aspirants to monitor preparation quality at subject/topic/test level.

## Features
- Subject analytics for Physics, Chemistry, and Mathematics.
- Topic-level revision priority ranking to identify weak areas.
- Daily streak + weekly consistency tracking.
- Mock-test trend tracking with weighted recency score.
- Overall preparation index and projected percentile estimate.

## Run
```bash
javac src/main/java/com/allen/tracker/JeeProgressTracker.java
java -cp src/main/java com.allen.tracker.JeeProgressTracker
```

## Notes
- This starter is intentionally self-contained (single source file) so it is easy to deploy and extend.
- Estimation formulas are planning heuristics and not official rank predictors.
